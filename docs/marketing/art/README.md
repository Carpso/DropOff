# DropOff marketing artwork

Generated by `tools/make_marketing_art.ps1` — re-run it after any price or copy change:

```powershell
powershell -File tools/make_marketing_art.ps1
```

The QR step needs the `qrcode` npm CLI at
`C:\Users\User\AppData\Local\Temp\opencode\qrgen` (`npm install qrcode` inside it).
The rest is pure Windows `System.Drawing` — no other dependency.

## qr/ — tagged QR codes (1200 × 1200, error correction H)

Each QR opens WhatsApp with a **different prefilled message**, so the first
message tells you which poster or ad produced the signup. Print the tag in
small text under the QR on every piece of collateral.

| File | Opens | Tag you will see |
|---|---|---|
| `qr-flier.png` | `wa.me/260968551110?text=FLYER` | `FLYER` |
| `qr-tiktok.png` | `…?text=SEND100-TT` | `SEND100-TT` |
| `qr-facebook.png` | `…?text=SEND100-FB` | `SEND100-FB` |
| `qr-status.png` | `…?text=SEND100-STATUS` | `SEND100-STATUS` |
| `qr-rider.png` | `…?text=RIDER` | `RIDER` (rider recruitment) |

**Print rule:** minimum 25 mm × 25 mm on paper, 40 mm on posters. Keep the
white margin — never crop into the quiet zone or it will not scan.

## Before you print or upload

1. **Prices must still match the live worker.** Check `PLANS` in
   `workers/src/index.ts` — if a price changed, re-run the script.
2. **The offer code must exist.** `SEND100` only works once ops has minted the
   100 one-time `rider_daily` pack codes. Do not print the flyer before the
   codes exist.
3. **Never add "insured".** Cover is quoted protection. The fine print on both
   flyers already says so — do not crop it out.
4. **Never print 0976847775.** Only `0968551110` appears on any artwork.
5. **Catalogue cards are square** — WhatsApp crops thumbnails to a square, so
   keep the price inside the middle 80% (already done).

## Editing

- Colours come from `app/lib/theme/app_colors.dart` (forest `#0E3B32`, amber
  `#F6B73C`). If the palette changes, update the constants at the top of the
  script.
- Card copy lives in the `New-CatalogueCard` calls at the bottom of the script.
  Keep bullets under ~40 characters or they wrap into the fine print.
- The script file **must stay UTF-8 with BOM** — Windows PowerShell 5.1 reads
  it as ANSI otherwise and every `·` and `—` turns into mojibake.
